## Response

### Limitation motivating the change

SenseNova-U1 used a lightweight visual interface that reconstructed each visual token as an independent RGB patch. This prevented neighboring patches from exchanging information during the final image-formation stage, causing seams, texture discontinuities, and geometric inconsistencies—especially at high resolutions. [1]

### How SenseNova-U1.5 addresses it

SenseNova-U1.5 replaces the patch-wise MLP decoder with a spatially coupled decoder. It restores the tokens to a 2D feature map, then progressively reconstructs the image using Pixel Shuffle upsampling and intervening \(3\times3\) convolutions. [2] [4]

These convolutions allow neighboring token regions to exchange information before pixels are finalized, so pixels near patch boundaries are determined jointly rather than independently. This improves cross-patch consistency, local continuity, and high-resolution generation while retaining compact visual tokenization. [3] [4]
