## How the native MoT attention pattern works

The native Mixture-of-Transformers (MoT) uses one Transformer backbone for both understanding and generation. Its sequence interleaves clean image–text context with noise-conditioned visual states, so semantic information, visual evidence, and generation can interact through shared self-attention. [1]

The key is that different token types receive different attention permissions:

1. **Text tokens remain causal.**  
   Each text token attends only to preceding context. This preserves the directional information flow required for causal language modeling. [1]

2. **Clean image tokens are bidirectional within their image block.**  
   Tokens belonging to a clean image may attend to one another in both directions. This allows them to capture spatial dependencies across the image rather than processing visual information only from one direction. [1]

3. **Noise-conditioned generation tokens are also bidirectional within their image block.**  
   Generation tokens can therefore interact with the other tokens in the same generated-image block. In addition, they attend to all preceding clean multimodal context, giving generation access to the relevant text and visual representations. [1]

4. **The reverse route is blocked.**  
   Clean representations cannot attend back to stochastic generation states. Thus, generation can use the clean semantic and visual context, but the understanding pathway is protected from being contaminated by the noisy generation states. [1]

## Reconciliation

The pattern reconciles the two objectives through **asymmetric masking**:

- The **text-to-text** pathway is causal, supporting autoregressive language modeling. [1]
- The **image-internal** pathways are bidirectional, supporting spatial visual interaction. [1]
- The **generation-to-context** pathway is open toward preceding clean multimodal information, allowing visual generation to use semantic context. [1]
- The **context-to-generation reverse pathway** is masked, preserving the integrity of representations used for understanding and reasoning. [1]

Therefore, “bidirectional” does not mean that every token can attend freely to every other token. Instead, the model uses causal attention for language, bidirectional attention inside visual blocks, and a one-way flow from clean multimodal context into generation. [1]

This attention design is combined with token-type-specific parameters: understanding and generation use separate attention projections, normalization layers, and feedforward modules, while shared attention provides the interface between the streams. [1] Thus, the architecture shares a representational space without forcing perception and synthesis to use exactly the same internal computation. [1]
